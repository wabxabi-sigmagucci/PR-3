# Практична робота №3/3.1


### Мета роботи
Розробити адаптивний вебінтерфейс дашборда відеохостингу або онлайн-курсу з використанням HTML5, CSS3 та JavaScript. Навчитися створювати Grid-макет, реалізовувати відеоплеєр, додавати інтерактивні елементи та забезпечувати доступність інтерфейсу.

Інтерфейс побудовано за допомогою CSS Grid і поділено на такі основні області:
- **Header** — логотип, поле пошуку, сповіщення та профіль користувача.
- **Sidebar** — навігаційне меню та інформація про прогрес навчання.
- **Main Content** — назва уроку, відеоплеєр, панель дій, опис уроку та вкладки з матеріалами.
- **Course Panel** — зміст курсу зі списком уроків і навчальними матеріалами.
- **Footer** — додаткова навігація та інформація про платформу.

### Використані технології
- **HTML5** — структура сторінки та семантична розмітка.
- **CSS3** — оформлення інтерфейсу, CSS Grid, Flexbox, адаптивність і стилізація елементів.
- **JavaScript** — інтерактивність, керування відеоплеєром, обробка подій і взаємодія з елементами сторінки.
- **SVG** — векторні іконки навігації та дій користувача.
